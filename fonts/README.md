# Fonts

이 디렉토리에는 재배포가 명시적으로 허용된 오픈소스 폰트(SIL OFL)만 포함합니다.

## 포함된 폰트
- `VT323-Regular.ttf` — 영문 타이틀용 (SIL OFL)
- `CourierPrime-Regular.ttf` — 로그 서버 화면용 (SIL OFL)

## 별도 준비가 필요한 폰트
- `KBIZ한마음명조 R.ttf` — 한글 본문 폰트. 파일 재배포 라이선스가 명시되어 있지 않아 저장소에서 제외했습니다.
  KBIZ(중소기업중앙회) 서체 배포 페이지에서 내려받아 이 폴더에 같은 파일명으로 넣어주세요.

전시 개발 과정에서는 여러 한글 픽셀 폰트(Galmuri, Neo둥근모, 조선일보명조 등)를 후보로 실험했으며,
동일한 이유(재배포 조건 불명확 또는 미사용)로 저장소에는 포함하지 않았습니다.
